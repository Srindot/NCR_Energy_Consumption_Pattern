# Project Setup Instructions

1. Clone the repository:
   ```bash
   git clone <repo-url>
   cd NCR_Energy_Consumption_Pattern
   ```

2. Create and activate the conda environment:
   ```bash
   conda env create -f environment.yml
   conda activate est_proj
   ```

3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

That's it. All dependencies will be installed from `environment.yml`.
